# Routing Module

Traffic controller of the server! Decides where incoming requests should go and ensures they reach the right handlers. Think of it as GPS for API endpoints.

## What It Does

- **Route Management**: Directs HTTP requests to the appropriate handlers
- **WebSocket Routing**: Manages WebSocket connection endpoints
- **Clean Organization**: Keeps API structure organized and maintainable
- **Flexible Endpoints**: Easily add new routes as application grows

Ensures that every request finds its way to the right destination, whether it's a simple HTTP call or a real-time WebSocket connection.
